# Convention
These are the conventions for variable names and file names.

## Directories
Directory names should be en kebab-case.
"directory-naming-style"

## File names
File names should always be in snake_case
"test_file.cpp"

## Variables
Variables should be camelCase, this also includes const variables

## Constants
Constants are only defined as compile time constants, this
means constexpr variables
Constants should be written in SCREAMING_SNAKE_CASE.
